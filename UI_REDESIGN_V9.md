# UI Redesign V9

The app UI was refreshed to follow the supplied Android Code Studio / Fluent-style reference:

- Blue brand accent with a very light neutral background.
- Large expressive page titles with supporting subtitles.
- Rounded 28dp grouped cards with thin outlines and clean dividers.
- Section labels use uppercase blue tracking.
- Material switches use a simple blue track + white thumb treatment.
- Choice/frequency/color rows share the same spacing and hierarchy.
- Music LED received the same visual system plus styled slider panels and effect chips.
- Automation sub-pages now use the same large page header and back navigation.
- Existing LED control, DataStore, Music LED microphone detection, priority gate and fade behavior are preserved.
